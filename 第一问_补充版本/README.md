## 目录和复现

`第一问/`集中放文字、图片、派生数据和Excel；`code/`保留实际求解器；`results/`保留正式JSON与独立验证。全部是普通文件，没有Windows目录联接。阅读已保存成果不需要安装运行环境。

原题、原始附件、原结果模板、第三问材料、运行环境与历史备份沿用原仓库惯例不上传。本目录中的`数据`指派生CSV；从零重算仍需自行持有原始附件。请把下列输入放在本目录根下，保留原题附件层级和文件名：

```text
第一问_补充版本/
├─ 数据/无人机应急物资运输基础数据/（调度中心与服务区、运输无人机数据、物资需求与配送时限三个xlsx）
├─ 数据/镇龙乡地理空间数据/镇龙乡及周边地理数据/数字高程模型数据（DEM）/镇龙乡及周边30米DEM.tif
├─ 山区洪涝灾害下无人机运输与通信协同优化.docx
└─ 结果提交模板.xlsx（仅重新导出基准Excel时需要）
```

使用Python 3.12，在本目录下安装`code/requirements_q1.txt`和`第一问/代码/requirements_paper.txt`，再按[详细运行顺序](code/README_Q1.md)执行。绘图当前使用Windows微软雅黑字体；Excel重导依赖Node.js与`@oai/artifact-tool`。先阅读现有Excel无需这些依赖。版本对照工具另外依赖原作者本机师兄目录与变更前备份，不是日常求解必需步骤。

`build_paper_package.py`用于本地材料汇编，重新运行前应准备原附件及`outputs/`中的重新导出Excel；它生成的含原附件ZIP仅供本地使用，已在本目录.gitignore排除。

## 核验与来源

正式求解代码、数值JSON、CSV、Excel和论文图片保持已验证源文件原字节。Markdown仅适配本仓库中的阅读入口和链接；没有重新运行优化或改动数学结果。[上传清单](UPLOAD_MANIFEST.json)逐文件记录原来源及当前SHA256，明确区分本次上传检查和历史计算检查。历史核验JSON里的本机绝对路径及缺省机器配置仅为溯源，不能当作收件人的运行目录。

原`第一问/结果/材料清单与核验.json`记录完整本地材料包（含原始附件）的检查；本GitHub目录是其中的分享子集，公开文件范围以本次上传清单为准。[代码修改记录](CODE_CHANGE_LOG.md)保留第一问相关历史及本次发布说明。
