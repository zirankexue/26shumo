# 第一问论文图组设计约定

图组依据当前局部椭球平面正式结果生成，使用项目现有 Python 工作流。所有数值是题给数据下的确定性模型计算值，不是实测重复样本，不绘制误差条或显著性检验。每幅图导出 600 dpi PNG、可编辑文字 SVG 和嵌入字体 PDF，常规图宽 180 mm，密集附图采用较高画布。正文按信息需要选图，不要求全部放进论文。

|编号|图形证据及核心结论|数据依据|主要误读风险及处理|
|---|---|---|---|
|F01|地形、节点及直达航线共同构成几何输入|原始DEM与正式航线|DEM背景仅作显示；实际最高值取全部相交原像元|
|F02|山脊决定巡航高度及双向爬升|S004/S008/S012相交像元|保守常值包络，不插值平滑|
|F03|服务区需求质量与体积分布不同|逐箱表与4类物资属性|双面板分别使用kg和L|
|F04|18批的整箱分组及B/C机型配置|基准batches|长度表示质量，箱数不由长度推断|
|F05|批次受质量、体积和能量三类容量约束|基准批次及机型参数|能量利用率分母是扣除20%余量后的预算|
|F06|水平飞行与爬升共同构成往返能耗|4个能耗分量|单独放大爬升，不把不同坐标轴视为同尺度|
|F07|累计作业时间包含飞行及地面操作|批次与机型时间参数|累计值不是多机并行完工时间|
|F08|20%余量下各机型安全载荷随航线变化|service_summary.safe_payloads|安全载荷只反映质量/能量，不代表体积可行|
|F09|完整前沿只有两个离散目标点|multiobjective.frontier|不连接为连续可选前沿；同时呈现时间代价|
|F10|Pareto差别源自S008一次C型改两次B型|两个前沿点的S008批次|同类箱可置换；展示实际代表组批|
|F11|余量变化触发阶梯式方案切换与最终不可行|19个精确interval_plans|真余量横轴；不可行区留空；阈值等号属于左侧方案|
|F12|19段方案的架次、能耗、时间并不等比例变化|19段目标及边界|纵轴是方案编号，不是等宽余量区间|
|F13|45组安全载荷曲线表现不同的能量限制|2745条payload_curves|曲线采样为1个百分点；不可行null断开，不补0|
|F14|末段极窄，但机型切换引起明显能耗跳变|R018/R019及B/C单箱阈值|使用相对余量百分点坐标放大，不掩盖区间宽度|
|F15|额定满载上限与空载极限界定载荷变化区|45组payloads|线段表示余量范围，不是置信区间|
|F16|候选枚举、数量DP、非支配DP与事件扫描构成求解链|求解器及实际计数|19是区间代表方案数，不是所有等价箱号解的数量|

F01为地形图与几何叠加，F16为算法结构图，其余以定量分面图为主。共用医疗/饮水/食品/卫生四类颜色，机型使用固定A/B/C编码，保留文字或符号以辅助灰度辨识。源CSV与图清单在运行绘图脚本时自动输出；详细图注和选图建议见《图表说明与选用建议》。
