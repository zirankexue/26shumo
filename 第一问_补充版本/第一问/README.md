# 第一问：论文写作与复现材料

本目录包含第一问的三个小项：整箱组批、多目标优化、返航安全余量敏感性。采用以O01为原点的局部椭球平面、题给3/2次幂航程关系和 g0=9.80665 m/s²。重力加速度按本次用户要求统一取标准重力，原题未强制其数值。

## 阅读顺序

1. [论文正文](文字/第一问_论文正文.md)：问题分析、数据与模型准备、假设与符号、模型建立、求解方法、结果讨论及19段附表。
2. [图表说明与选用建议](文字/图表说明与选用建议.md)：16幅图的图注、用途、PNG/PDF/SVG和源数据链接。
3. [论文图册](图片/第一问_论文图册.pdf)：逐页浏览全部16幅图；使用时从单幅PDF/SVG提取矢量图，或插入600dpi PNG。
4. [数据来源与处理说明](文字/数据来源与处理说明.md)及[字段字典](数据/data_dictionary.csv)：原始数据与派生字段、单位、空值和精度口径。
5. [写作说明](文字/写作说明.md)：论断与证据对应、适用边界及引用说明。
6. [与师兄版本的差异及统一说明](文字/与师兄版本的差异及统一说明.md)：当前对照结论、已统一细节、新旧数值变化及19段深入分析的保留情况。

## 已保留的核心成果

- 80箱、758 kg、2.011 m³全部交付；20%余量下18架次，B/C型各9架次，总能耗59.13226032599277 kWh，累计作业32776.5167822769 s。
- 完整Pareto前沿2个离散点，保留两套完整箱号方案、六种完整目标排序的端点及S008拆批代价。
- 742个容量可行候选、110个内部临界值、111个基本区间、19段最优代表方案与18次转换。
- 45组机型—航线载荷、2745个曲线样点、18个典型情景（含5%—45%九档常规对照）、单箱上限及精确可行余量上限35.26764734919061%。
- 正式JSON与独立验证证据见[上一级results目录](../results)。19段不是全部等价箱号最优解的枚举数量。
