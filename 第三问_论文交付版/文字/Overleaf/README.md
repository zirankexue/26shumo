# 第三问文字与图片使用说明

正文主方案为21个运输架次加3个中继架次，总能耗66.445273 kWh、联合完工6612.284 s。22个运输架次加3个中继架次仅作运输下限对照。两问使用同一权重和固定归一化尺度；问题二基准取本次下载工程中的22架次、65.722736 kWh、5792.178 s。

## Word预览

打开“第三问_建模与求解.docx”。该文件含完整正文、8幅内嵌图、4张正文表和5张附录表。公式采用原生Office Math，可编辑。Word编号按当前工程的第6节示例显示，独立附录从A开始。

## 复制到已有Overleaf工程

1. 将“第三问正文_可直接粘贴.tex”的全部内容复制到原工程的 `sections/problem3.tex`。本文件已展开4张正文表，无需再上传正文表文件。
2. 将本目录 `Overleaf/figures/q3` 中的8张PDF按相同路径上传到原工程，即 `figures/q3/*.pdf`。图片文件名不要修改。
3. 将“第三问附录_可直接粘贴.tex”复制成 `sections/q3_appendix.tex`。它已展开5张附录表。
4. 在原工程 `main.tex` 的 `\appendix` 后、已有附录之后，加入 `\clearpage` 和 `\input{sections/q3_appendix}`。正文已有 `\input{sections/problem3}` 时无需重复添加。
5. 使用XeLaTeX连续编译两次，使图表、公式及附录引用更新。正式编号随原工程自动变化，不要在正文手动改图号或公式号。

正文引用了逐箱交付附录，因此第3、4步应一并完成。本文使用的 `\qThreeFigDir` 默认是 `figures/q3`；所有label均有q3前缀。

## 按目录上传

也可解压“第三问_Overleaf.zip”，将 `sections`、`table/q3`、`figures/q3` 合并上传到原工程。目录版正文通过 `\input{table/q3/...}` 引表，内容与展开版一致；二者选一种，不要同时把两份正文插入主文档。

包内 `q3_preview.tex` 可在已有 `gmcm2026.cls` 和 `fonts` 的原工程内单独编译。压缩包不包含也不替换原工程的 `main.tex`、配置、第一问或第二问。独立预览附录编号从A开始，插入完整论文后会自动接续已有附录。

## 图片与复现

第三问“图片”目录保留每图的PDF矢量版、SVG可编辑版和600 dpi PNG；LaTeX引用PDF，Word嵌入PNG。8张图依次为技术路线、运输与中继位置、联合时序、连续通信、逐箱交付、机电资源、可行性裕量、方案比较。

文稿数据冻结在 `第三问/数据/论文用数据`，来源和SHA-256见该目录的 `source_manifest.json`。生成代码在 `第三问/代码`。当前稿只读取原正式解和对照解，不修改它们；有限候选与限时搜索结果未被写成全局最优证明。
