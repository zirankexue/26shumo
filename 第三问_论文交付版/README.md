# 第三问论文交付版

这是与 `第三问_补充版本` 同级的独立论文材料目录，保存本次交付的 Word 预览版、可直接粘贴的 LaTeX、Overleaf 增量工程和论文配图。本目录不覆盖、不修改 `第三问_补充版本`，也不包含第三问求解源码、运行缓存或本机临时文件。

## 主方案

- 21 个运输架次 + 3 个中继架次。
- 总能耗 `66.445273 kWh`，联合完工时间 `6612.284 s`。
- 80 个货箱全部按期交付，240 个连续通信区间通过认证。
- 22 个运输架次 + 3 个中继架次仅作为对照：总能耗 `66.035704 kWh`；在固定权重和固定归一化尺度下，其综合评分高于主方案。
- 结果是当前有限候选与搜索设置下的可行方案，不表述为未受限全局最优证明。

## 图片

图片目录同时保留 LaTeX 使用的 PDF、可编辑 SVG 和 600 dpi PNG，图件内容与文件名见 [figure_manifest.json](图片/figure_manifest.json)。Overleaf 目录中的 8 张 PDF 是可直接合并到原工程 `figures/q3` 的副本。

## 完整性

`UPLOAD_MANIFEST.json` 记录本次上传文件的目标路径、字节数和 SHA-256。上传范围仅限本目录中的论文交付材料；原始数据、求解代码和历史补充版本仍在各自目录中独立维护。
