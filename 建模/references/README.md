## 目录与复核

- `pdf/`：下载所得文件，保留原始字节；论文预印本和官方终版分开标注。
- `web_pdf/`：5份自行生成的网页正文存档。
- `web/`：原始HTML及部分失败响应/接口响应，用于检索核查，不能仅凭HTTP 200认为拿到了正文。
- `metadata/`：请求URL、最终URL、时间、状态、文件哈希、书目数据和获取失败原因。
- `text/`：逐页提取的PDF文字JSON/TXT、网页文本。数学结构可能被抽取破坏，应回看原PDF。
- `previews/`：公式页面及存档版式的检查图，不替代原文。

下载使用正常HTTPS证书验证；Python证书库失败时，使用Windows Schannel信任库的curl重试，没有关闭TLS验证。文件同时检查`%PDF-`标识、解析能力、页数及正文身份，防止把错误页保存成PDF。成功下载不等于完成全部内容的实证验证。

后续加入新文献时延续[公式来源审计](../docs/公式来源与假设审计.md)的分类规则。对已经下载的论文，引用本文具体版本和PDF页码；对网页只能引用网页段落/参数项，不能编造原文公式编号。
