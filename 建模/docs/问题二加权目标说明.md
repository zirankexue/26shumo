# 问题二四指标加权权衡

用户已确认主权重为 **W:Cmax:E:N=3:1.5:1:0.5**。本扩展把权重真正用于优化、搜索接受和推荐方案选择，并进行四个单项权重放大情景。原四种词典序方案保留为严格优先关系的对照和热启动来源，不能改名为本次加权情景结果。

## 1. 指标、固定归一化与主权重

四个成本指标为 f=(W,Cmax,E,N)，全部越小越好。其中 W=Σ_b w_b max(0,C_b−d_b) 仍为加权迟到，单位为优先系数·秒；Cmax 为最后一架运输机返航时刻，单位秒；E 为运输能耗，单位kWh；N 为架次数。W不混入平均交付时刻，w_b是原始逐箱优先系数，α_j是四目标之间的偏好权重，两者不同。

从四个旧词典序完整方案固定参考下端 l_j=min f_j、上端 u_j=max f_j，以及尺度 s_j=u_j−l_j。若某指标在四方案中完全相同，以该指标1个自然单位作尺度，仍保留该目标。定义：

\[
z_j(f)=\frac{f_j-l_j}{s_j},\qquad
F(f)=\sum_j\alpha_j z_j(f),\qquad
\alpha=(1/2,1/4,1/6,1/12).
\]

所有α_j均为正且和为1；z_j与F无量纲，数值不保证为正。参考范围在新搜索开始前冻结，四个加权情景使用同一组l、u、s，不裁剪z；新方案可以落在[0,1]之外。参考端点是已见四方案的比较尺度，不是原问题的全局理想点或劣点。

3:1.5:1:0.5是用户确认的决策偏好，不宣称来自题面、实测或文献。固定归一化来自单位抵消的直接推导，加权和属于显式决策构造。两方案的变化量为ΔF=Σ_j α_j Δf_j/s_j，因此真实交换关系由权重和尺度共同决定，必须一起保存；不能把不同量纲的W、秒、kWh和架次数直接按该比值相加。

31个有效硬截止、货箱唯一交付、质量、体积、返航SOC、无人机和电池资源始终是硬约束，不能由较低能耗或较少架次抵消违反。硬截止的医疗与首批交集仍取更严格值，沿用独立验证器。

## 2. 主搜索与四个权重情景

实现以`src/uav_rescue/q2/weighted_run.py`和`configs/q2_weighted.toml`为准。步骤如下：

1. 从旧正式结果与候选缓存读取四个完整方案；从原始数据重新构造候选、重算物理可行性，并核对来源哈希。比较四个方案的主权重分数，选取较好者作热启动。旧结果及检查点不被覆盖，不读取恢复检查点。
2. 主权重阶段依次进行120秒初始CP-SAT、360秒ALNS搜索及120秒CP-SAT收尾。ALNS采用随机、邻近、迟到与末段瓶颈破坏，结合贪心与regret-2修复生成新候选。修复阶段的单路线代理沿用四种旧目标顺序轮换，仅用于候选多样化；完整方案的接受和最好解更新均用F。
3. 主权重阶段结束后，冻结该阶段最好方案作四个情景的共同起点。每个情景独立放大一个权重10倍，其他三个原始权重保持不变，再除以权重和计算该情景的α。四种原始比值依次为`30:1.5:1:0.5`、`3:15:1:0.5`、`3:1.5:10:0.5`和`3:1.5:1:5`。它们表示更强的有限偏好，不等于无限优先的词典序。
4. 每个情景默认进行3000轮快速ALNS扰动和列表调度，再用该情景目标执行60秒CP-SAT精修。快速阶段只从主搜索结束时的候选池重选组批，重排调度；不新增候选航线。每轮破坏3—8个架次，从被释放货箱中按贪心或regret-2选取可覆盖候选，列表调度同时考虑同型无人机与满电电池可用时刻。该阶段用构造箱序；最后CP-SAT阶段可在候选池内重新选择架次，并优化箱序与开始时刻。
5. 每个返回的完整可行解都用主权重F重新评分。主权重最好方案单独保存，不因某情景接受较差解而被覆盖；各情景独立搜索的最好终点保存在`scenario_search_endpoints`中，作为搜索过程的原始证据。主方案仍是旧四个完整方案与本次新搜索实际返回、通过独立重算的方案中，主权重分数最低者。
6. 四情景完成后，对保存了完整运输、交箱与资源时序的9个方案进行跨情景回评：主权重最好方案、四个独立情景终点及四个旧词典序方案构成共同备选集。对每个情景，按该情景自身权重从共同备选集中重选评分最低者，作为最终情景展示方案；这一步只重新评分和选取，不重新求解。原独立搜索终点保留，不被新的展示方案抹去。只有目标向量的`cloud`记录不具备完整可核验时序，不参与重选。

独立搜索终点可能被另一个情景已找到的完整方案支配，因此不能直接把各次搜索终点都称为各权重下的“最好方案”。本次9方案回评后，及时性放大情景采用`weighted`，完工时间放大情景采用`scenario_makespan`，能耗放大情景采用`scenario_energy`，架次放大情景也采用`scenario_energy`；主推荐不变。这是已保存完整方案内的比较结论，不是重新运行四次搜索，也不保证各权重的全局最优。不同情景选中同一方案时，表格和曲线保留重复，明确标注，不人为制造不同终点。

破坏/修复算子按奖励5/3/1/0更新权重，反应系数0.2、下限0.1；改进解接受，较差解按exp(−ΔF/T)接受，温度由0.05几何下降至0.001。主阶段温度按阶段用时变化，快速情景按迭代进度变化。种子为0、1、2按配置轮换，候选池上限1500，保护旧四方案及主搜索当前/最好方案。以上均是搜索设置，不是物理规律。

默认计时阶段合计840秒；四个情景共12000轮快速调度、独立验证及导出耗时另计。`--budget-seconds`按比例缩放上述计时阶段，**不是整个程序的严格墙钟上限**；`--iterations`单独覆盖每个情景的快速迭代次数。实际耗时和完成迭代数由结果日志记录，不预填计算结果。

## 3. 数值精度、误差界与推荐范围

时间沿用1毫秒调度精度，航段持续时间向上取整，截止不放宽；每条候选路线的能耗目标按1e−9 kWh四舍五入。代码中的W、Cmax、E、N分别以优先系数·毫秒、毫秒、1e−9 kWh和架次计量，参考端点与尺度同步换算，因此不改变无量纲评分。

为避免CP-SAT整数目标系数的巨大公分母，令P=10^6，以同一内部单位构造：

\[
r_j=\left\lceil\frac{P f_j}{s_j}\right\rceil,\qquad
I=\sum_j a_j r_j,
\]

其中主权重的最简正整数比例a=(6,3,2,1)，情景使用相应整数比例。减去l_j/s_j是与方案无关的常量，可从求解表达式中省略。令A=Σa_j，则：

\[
\widehat F=\frac{I}{AP}-\sum_j\alpha_j\frac{l_j}{s_j},\qquad
0\le\widehat F-F<1/P.
\]

该界由0≤ceil(x)−x<1逐项乘正权并求和直接得到；它只覆盖整数归一化近似。两方案评分差的附加误差绝对值小于1/P，因此极近的F排序可能不同；最终保存与推荐直接比较未做该二次取整的F，不能把整数目标的OPTIMAL宣称为原连续评分的精确最优。

上述F仍以调度离散指标为基础。相对于未量化物理能耗，N条架次的能耗目标量化误差至多为N×0.5×10^−9 kWh；换到固定评分中的误差至多为α_E N×0.5×10^−9/s_E（此处s_E用kWh）。1/P界不包含这一误差，也不包含毫秒时间离散的影响。容量、能耗预算和SOC继续使用未量化物理值核验。

CP-SAT状态的最优性只涉及当次候选池、该次约束与整数评分；ALNS及快速列表调度不能证明原问题全局最优。主推荐只保证实际返回且核验通过的完整可行方案中的主权重最好；四个最终情景只保证共同9方案备选集内按各自权重最好。有限情景和散点均不是完整Pareto前沿。

## 4. 输出与复现

```powershell
python run_q2_weighted.py --config configs/q2_weighted.toml
python run_q2_weighted.py --config configs/q2_weighted.toml --report-only
```

输出独立保存在`outputs/q2_weighted/`。同名旧加权输出先归档，`outputs/q2/`中旧词典序结果保留。结果应区分加权推荐、四个情景独立搜索终点、跨情景回评后的四个最终情景，以及旧词典序对照，保存权重、固定尺度、每个完整方案及来源、实际耗时、搜索/接受轨迹和独立验证信息。重导出读取已保存结果，不重新运行优化；本次跨情景回评不读取或检查恢复检查点。

五方案平行坐标展示加权推荐及跨情景回评后的四个放大权重情景，使用同一冻结尺度，并标明实际单位与重复方案；时间—能耗图以颜色表示W、点面积表示N。云图保留全部`accepted=True`记录，并未按向量去重绘制；重复记录会在同一位置叠加。本次已保存1027条此类记录，对应538个唯一四指标向量，记录中还包括参考方案和情景终点，不能解释为1027次独立接受迭代或538种不同航线结构。唯一向量数只是统计量，最终以数据日志为准。旧轨迹只提供目标向量时，应标清其来源及缺乏完整时序的限制，不能从散点中直接选取无法复算的“更优方案”。
